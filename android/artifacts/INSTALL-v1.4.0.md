# تثبيت وتحديث ReWord 1.4.0

نزّل [ReWord-v1.4.0.apk](https://github.com/reyad-dev/reword-by-reyad/releases/download/v1.4.0/ReWord-v1.4.0.apk). اسم الحزمة `com.reword.app`، الإصدار **1.4.0**، وكود الإصدار **10**.

## التحديث من النسخة الحالية

التوقيع مطابق لنسخ 1.3.0 و1.3.1 و1.3.3. ثبّت الملف فوق النسخة الحالية دون حذف التطبيق؛ تظل بيانات الخزنة محفوظة. نسخ أقدم ذات توقيع مختلف تحتاج اتباع [دليل النسخ القديمة وحماية البيانات](INSTALL-v1.3.3.md) أولاً.

**تحتاج تثبيت 1.4.0 يدوياً مرة واحدة لتفعيل تنبيهات التحديث**؛ النسخ السابقة لا تحتوي على الفحص. بعد ذلك، يفحص التطبيق GitHub عند فتحه أو الرجوع إليه، مرة كل 12 ساعة بعد آخر فحص ناجح. عند وجود نسخة أحدث يظهر «إصدار جديد من ReWord» مع زر «تحميل التحديث» وخيار «لاحقاً». ويمكنك الفحص في أي وقت من الإعدادات ← تحديث التطبيق.

زر التحميل يفتح APK الرسمي في المتصفح. بعد التنزيل افتح الملف وأكّد التحديث من أندرويد، واسمح للمتصفح بتثبيت التطبيقات عند طلب النظام ذلك. لا يتم التثبيت تلقائياً.


راجع [SHA256SUMS-v1.4.0.txt](SHA256SUMS-v1.4.0.txt) لبصمات الملفات.

## نشر تحديثات أندرويد القادمة عبر GitHub

1. ارفع `versionCode` و`versionName` في `android/app/build.gradle.kts`، مع استخدام رقم إصدار ثابت من ثلاثة أجزاء، مثل `1.4.1`.
2. شغّل `testDebugUnitTest assembleDebug lintDebug` وابنِ APK **بنفس مفتاح توقيع الإصدار المثبت**. احتفظ بالمفتاح محلياً في مكان آمن؛ لا ترفعه إلى المستودع. البناء الحالي يستعمل مفتاح debug المحلي الموجود منذ النسخ السابقة. ملفات APK الناتجة عن GitHub Actions تستعمل مفتاحاً مختلفاً مؤقتاً، فلا تنشرها كتحديث للمستخدمين.
3. تحقّق من الحزمة ورقم الإصدار والتوقيع، ثم انشر GitHub Release عام غير تجريبي بوسم مثل `v1.4.1`، وأرفق الملف بالاسم المطابق تماماً: `ReWord-v1.4.1.apk`.
4. هذه الخطوة تكفي لاكتشاف التحديث من التطبيق. لا تحتاج سيرفر إضافي. إصدارات الإكستنشن بوسم `chrome-v…` لا تدخل في فحص أندرويد.

الفحص يقرأ آخر 100 إصدار عام من المستودع، ويتأكد من وجود APK بالاسم والرابط الرسميين، ويختار أعلى إصدار أحدث من المثبت. لا يرسل معرف الخزنة أو كلمات المرور أو بيانات الحسابات إلى GitHub.
